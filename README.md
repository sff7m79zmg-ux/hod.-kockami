### Part 1
As mentioned above, I started by creating a program that simulates rolling a single die 

First, I imported the `random` module, which provides functions for generating pseudorandom numbers.

A pseudorandom number is generated by an algorithm and appears random, but its sequence is determined by an initial state called a seed.

Then, I used `random.randint(1,6)` to genetate a pseudorandom integer between 1 and 6, including both limits. The `randint()` function can also be used with other integer ranges, depending on the values provided.

Next, I needed to store the result of the roll, so I created a variable called `kocka1`. Finally, I used `print(kocka1)` to display the result in terminal.
